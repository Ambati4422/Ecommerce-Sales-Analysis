# Ecommerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data to understand sales trends, profitability, product performance, customer contributions, and regional results. The data was cleaned with Python, summarized in Excel, queried with SQL, and presented in an interactive Power BI dashboard.

## Project Objectives

- Prepare the sales data for analysis by cleaning and validating it.
- Summarize key sales and profit measures.
- Answer business questions using SQL queries.
- Present important findings through Power BI dashboard visuals.

## Tools Used

- **Python** — data cleaning and preparation
- **Microsoft Excel** — summaries, pivot tables, and charts
- **SQL** — querying and analyzing the cleaned data
- **Microsoft Power BI** — interactive dashboard and visual reporting

## Project Workflow

1. **Data cleaning:** Used Python to prepare the dataset, handle data quality issues, and create a cleaned file for analysis.
2. **Excel analysis:** Summarized the cleaned data and prepared supporting tables and charts.
3. **SQL analysis:** Wrote queries to investigate sales, profit, customers, products, regions, markets, discounts, and shipping modes.
4. **Power BI dashboard:** Built an interactive dashboard to present key performance measures and trends.
5. **Dashboard screenshots:** Included screenshots in this repository so readers can preview the dashboard without opening the Power BI file.

## Business Questions

- Which market and region generate the highest sales?
- How do sales change over time?
- Which products and sub-categories generate the most profit?
- Which customers contribute the highest sales?
- Which categories have the lowest profit?
- Which category has the highest average discount?
- Which order lines have negative profit?
- Which shipping modes are used most often?
